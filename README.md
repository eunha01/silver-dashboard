# ☕ 주식회사 카페프리헷 - 실버의 업무 대시보드 (Fríhet Dashboard)

주식회사 카페프리헷 경영지원팀(실버 담당)을 위한 통합 세무·회계 및 자금 관리 업무 대시보드입니다.

---

## 🌟 주요 기능

1. **종합 대시보드**
   - 세무 및 회계 사무실 제출 체크리스트 (분기별 9대 점검)
   - 매출/초도물품 제조금액 구분 자동 계산기 (92:8 및 50:50)
   - 최근 이체 및 세금계산서 발행 현황 요약
   - 금주 오픈 매장(초도물품, 머신설치, 삼성카드) 스케줄 요약

2. **매일 이체 내역 & 세금계산서 관리**
   - 실시간 내역 검색 (업체명, 적요, 날짜 등)
   - 테이블 헤더 클릭 정렬 (이체일, 구분, 업체명, 금액 등)
   - 클립보드 원클릭 포맷 복사 (`날짜 거래처 / 금액 - 내용`)
   - 세금계산서 미완료 건만 필터링 및 전체 복사
   - 데일리 업무 메모장 (실시간 브라우저 자동 저장)
   - 엑셀 CSV 내보내기

3. **매월 정기결제 관리 (고정비 16개처)**
   - 매월 반복되는 고정 지출처 관리 및 업체명 자유 수정
   - 당월 정산 제외 토글 및 세금계산서 발행일 기록

4. **개인거래처 납품 관리 (B2B)**
   - 호텔, 기업 등 원두 납품 품목 및 금액 기록
   - 계산서 발행 및 수금 완료 더블 체크

5. **매장 일정 & 청년일자리도약장려금**
   - 초도물품 발주, 머신 설치 및 대금 정산 3단계 추적, 삼성카드 결제 관리
   - 매월 10일 급여 지급 후 청년도약장려금 신청 대상자 체크리스트

6. **업무 캘린더**
   - 월별 주요 세무/급여 마감 일정 및 이체 일정 시각화

7. **데이터 백업 & 복원 엔진**
   - 상단 `[데이터 백업]` 클릭 시 전체 데이터를 JSON 파일로 다운로드
   - 상단 `[데이터 복원]` 클릭 시 백업 파일 선택으로 1초 만에 데이터 원상 복구

## 🚀 GitHub Pages 배포 방법 (초간단 3단계)

1. 이 저장소(Repository)의 모든 파일을 올립니다 (`index.html`, `style.css`, `app.js`, `README.md`, `.nojekyll`).
2. 저장소 상단의 **Settings** 메뉴로 이동합니다.
3. 좌측 사이드바의 **Pages** 클릭 후:
   - **Branch**: `main` (또는 `master`) 선택
   - **Folder**: `/(root)` 선택
   - **Save** 버튼 클릭!
4. 약 1분 후 제공되는 사이트 주소(`https://<사용자이름>.github.io/<저장소이름>/`)로 접속하시면 어디서든 바로 사용하실 수 있습니다!
